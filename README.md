# Система адаптации менеджеров по продажам

Индивидуальный предприниматель хочет автоматизировать адаптацию новых менеджеров по продажам на основе внутренних документов компании.  
Цель — сократить время онбординга, уменьшить нагрузку на руководителя отдела продаж и обеспечить стабильное качество подготовки через автоматически генерируемые обучающие курсы и тесты.

Бэкенд-сервис принимает корпоративные документы, преобразует их в структуру курса, генерирует тесты и предоставляет API для интеграции с другими модулями (диалоговый тренажёр, аналитика).

---

## Пользователи системы

- **Индивидуальный предприниматель (заказчик)**
  - Инициирует разработку и внедрение системы.
  - Ожидает снижения затрат на адаптацию и роста эффективности новых сотрудников.

- **Руководитель отдела продаж**
  - Загружает и обновляет документы.
  - Запускает генерацию курсов и тестов.
  - Редактирует и утверждает учебные материалы.
  - Анализирует результаты тестирования стажёров.

- **Стажёры (новые менеджеры по продажам)**
  - Проходят обучающие курсы.
  - Выполняют тесты и мини-контрольные.
  - Получают обратную связь по ошибкам.

- **Опытные менеджеры по продажам**
  - Используют курсы и документы как справочник по продукту и регламентам.
  - При необходимости проходят обновлённые модули обучения.

- **Разработчик диалогового тренажёра**
  - Получает через API структуру курсов и тестов.
  - Строит на их основе диалоговые сценарии обучения.

- **Разработчик модуля аналитики**
  - Получает через API результаты тестов и активность пользователей.
  - Формирует отчёты и дашборды для руководителя.

---

## Требования

### Работа с документами

- Загрузка внутренних документов компании через веб-интерфейс или API (например, PDF, DOCX, TXT).
- Удаление устаревших или ошибочных документов.
- Парсинг и обработка документов:
  - очистка от служебной информации;
  - разбиение на смысловые блоки;
  - подготовка данных для последующей генерации курса.

### Генерация и управление курсами

- Автоматическая генерация структуры обучающего курса на основе загруженных документов (с использованием LLM).
- Просмотр черновика курса руководителем отдела продаж.
- Ручное редактирование структуры курса, модулей и отдельных материалов.
- Утверждение курса для публикации.
- Хранение нескольких версий курсов.
- Доступ стажёров только к последней утверждённой версии курса.

### Генерация и выполнение тестов

- Автоматическая генерация тестовых заданий на основе утверждённого курса.
- Поддержка вопросников разного типа (например, выбор одного/нескольких вариантов ответа, открытые вопросы).
- Генерация ежедневных мини-контрольных (3–5 вопросов) на основе истории ошибок конкретного стажёра.
- Возможность просмотра и редактирования тестов руководителем отдела продаж.
- Сохранение:
  - результатов прохождения тестов;
  - истории попыток;
  - типичных ошибок стажёров.

### Доступ и интеграция

- Личный кабинет стажёра и опытного менеджера:
  - список доступных курсов;
  - прохождение уроков и тестов;
  - просмотр результатов.
- Ролевое разграничение доступа (руководитель / стажёр / опытный менеджер / внешние сервисы).
- API для:
  - получения структуры курсов и тестов (диалоговый тренажёр);
  - выгрузки результатов тестирования и активности (модуль аналитики).
- Уведомления:
  - руководителю — о необходимости обновить курсы и тесты при изменении документов;
  - пользователям — об обновлении учебных материалов и новых тестах.
